Welcome!

b0r3d-city is a custom b0r3d.org build based on micropolisJS, a handmade Javascript port of the open-source city simulator Micropolis

Heads up: touch controls (tap-to-place, drag-to-pan, pinch-to-zoom) are still experimental—everything should work, but expect some rough edges.
